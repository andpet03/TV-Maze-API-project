LEARN BY LOOKING

Under the hood.

Your browser is the client. It sends a GET request to TVmaze’s server. The server returns JSON; this app turns it into shows and episodes.

01. Search/search/shows?q=TITLEA query parameter carries your title. Results contain show IDs.
02. Identify/shows/IDAn ID selects the exact series, even when names are identical.
03. Explore/shows/ID/episodes?specials=1Includes specials. Filtering and the evening planner then run locally.

A CACHE entry reuses data from this tab for up to 5 minutes. It is not a new network call. HTTP 429 and server errors get one bounded retry. No API key or backend is required.

TAKE YOUR SHELF WITH YOU

Backup & restore.

Download your watchlist and episode progress as a JSON backup. You can restore it in another browser.

Only your watchlist, watched episode IDs, and last known progress are saved. There is no cloud account or cross-device sync. Clearing browser storage removes local progress; keep a backup.
